# Content batch 02 (2026-10-20)

Second batch for the MediaForge content engine, 50 vertical (9:16) videos for AlbertaWeb.Design and @buildwithdb:

- 30 narrated stories (AW16-AW30, DB16-DB30): the owner's cloned voice, kinetic captions, hook and brand end card over **smooth** drone footage (`min_smoothness` 0.8, no hyperlapses). ADs get a Suno music bed (levels are normalised by the renderer); ORG videos are voice-only.
- 16 B-roll videos (AW-B16..B23, DB-B16..B23): 32 s, cut on the beat (5 with music, 3 silent per brand), same smooth-footage rules, a different 5-video exclusion window per brand.
- 4 hyperlapse compilations (AW-HL-DAY, DB-HL-DAY, AW-HL-NIGHT, DB-HL-NIGHT): every day / night(+dusk) hyperlapse in one video, with music that must cover the natural length plus the end card without looping.

Files: `SCRIPTS.md` (narrated scripts, hooks, hints, posts), `manifest.json` (generated by the runner from SCRIPTS.md plus the assignments at the top of `run_batch.py`; edit it freely), `run_batch.py` (stdlib-only runner), `qc_whisper.py` (speech-QC helper that the runner starts with the MediaForge venv).

```
python3 -I run_batch.py --dry-run                 # requests + music-fit table, sends nothing
python3 -I run_batch.py                           # run everything not finished (resumable)
python3 -I run_batch.py --only AW-HL-DAY          # specific IDs
python3 -I run_batch.py --rerender narrated-music # re-render stored story plans (no ElevenLabs)
python3 -I run_batch.py --qc-only AW17,DB22       # speech QC on existing narrated files
```

Order: narrated AW16-30, DB16-30, then B-roll, then compilations. Each narrated render is checked with faster-whisper "small" (CPU): the share of script words heard goes into `state.json` and the summary, and below 85% is flagged QC-WARN (review by ear; never a failure).

Music start points are always downbeats chosen so the track covers the video plus the 1.8 s end card without looping ("2nd" = ~40 s after the best section, or the furthest fitting downbeat if the track is short). The runner reads `MF_API_TOKEN` from `/home/g15/mediaforge/.env` at run time and never writes it anywhere. Rendered files live outside the repo in `~/astra6/finished-content/batch-02/`.
