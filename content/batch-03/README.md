# Content batch 03: PHP2Shell news response (2026-10-22)

Breaking-news content for both brands with no camera footage: 6 narrated videos (AW31-33, DB31-33) whose beats mix smooth drone B-roll with locally rendered motion-graphic cards (headline, stat, alert, terminal, timeline), and 6 music-led / silent B-roll videos (AW-B24..26, DB-B24..26).

- `SCRIPTS.md`: verified facts, scripts, hooks, `[CARD kind: text | sub]` markup, music and posts.
- `manifest.json`: generated by the runner from `SCRIPTS.md` (edit it freely). Narrated entries carry `beat_visuals`, the list sent to `POST /api/edits/story`.
- `run_batch.py`: stdlib-only runner derived from batch 02's (resume, `--only`, `--redo`, `--rerender`, `--dry-run`, speech QC, QC sheets, POSTS.md, per-brand asset-usage cap). Beats replaced by cards do not count towards the usage cap.
- `qc_whisper.py`: speech-QC helper (MediaForge venv).

```
python3 -I run_batch.py --dry-run
python3 -I run_batch.py
```

Card duration always equals the beat's voice slot, so narration sync is unchanged; captions render on top of the cards. Rendered files live outside the repo in `~/astra6/finished-content/batch-03/`.
