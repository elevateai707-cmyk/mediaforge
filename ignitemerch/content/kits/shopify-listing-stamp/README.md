# Shopify Listing Stamp Pack
Version 1.0.0 · Commercial license

Titles, bullets, and photo prompts for a Shopify or Etsy listing that sells a digital kit.

## Why this SKU
Listing copy is a job, not a “100 ChatGPT prompts” grab bag. This pack is for one product type: downloadable operator kits priced $29–$79.

## You get
1. `titles.md` — 24 title formulas with character limits.
2. `bullets.md` — 8 bullet patterns (who, tonight, not-for).
3. `photo-prompts.md` — 12 stills that match Heat Press Photo Desk outputs.
4. `seo.md` — one primary phrase per listing, no stuffing.
5. `qa.md` — banned phrases (unlock, transform, 10x).

## Rule
One listing, one promise. If the title names UGC, the bullets cannot pivot to n8n.
