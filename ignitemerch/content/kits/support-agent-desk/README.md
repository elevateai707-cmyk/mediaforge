# Support Agent Prompt Desk
Version 1.0.0 · Commercial license

57 prompts for a customer-support agent that already has your policy docs. Not 500 ChatGPT prompts.

## Why this SKU
Gumroad data on thousands of prompt products shows the $10–$19 band is a revenue dead zone, and specificity (“prompts for your support agent”) beats generic libraries.

## You get
1. `prompts/refund.md`
2. `prompts/download-failed.md`
3. `prompts/license.md`
4. `prompts/chargeback.md`
5. `prompts/escalation.md`
6. `eval/cases.md` — 12 tickets to run before you go live.

Each prompt has one `{placeholder}` style and a worked reply.

## Guardrails
Never invent an order ID. Never promise a refund the policy does not allow. If Stripe status is unknown, say so.
