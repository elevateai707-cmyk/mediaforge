# Cursor Agency Skill Drop
Version 1.0.0 · Commercial license

Rules and skills for shipping client sites in Cursor without the agent inventing a second design system.

## Why this SKU
Generic prompt packs are a dead zone. Operator skills (rules, skills, CLAUDE.md) are still scarce, and agencies already pay for them internally.

## You get
1. `.cursor/rules/agency-delivery.mdc` — scope lock, no extra pages, no fake metrics.
2. `.cursor/rules/front-end-press.mdc` — type, color, motion bans.
3. `skills/qa-pass/SKILL.md` — checklist the agent must run before it says done.
4. `skills/handoff/SKILL.md` — client handoff doc format.
5. `CLAUDE.md` — same rules for Claude Code.

## How to install
Copy into the client repo. Keep the rules always-on. Do not paste the whole pack into chat.

## What it stops
- Inter / purple-gradient landing pages
- Invented testimonials
- Extra dashboard routes you did not ask for
- `transition: all`
