# Negatives that stop melted logos

Use this block on every lifestyle run:

```
melted logo, warped type, extra product, missing label, busy room, neon gel, plastic shine, fake watermark, text overlay, hands, mannequin horror, cloth fused to skin, double bottle, barcode smear, jpeg blocks, oversharpen halo
```

If type still melts:
1. Lower denoise to 0.28.
2. Crop tighter on the label and run a detail pass only on that crop.
3. Reshoot. A 600px source will not hold a wordmark.
